# EVA Core

EVA Core is an Apache-2.0, fail-closed authorization library for AI agents.

It provides:

- Local policy evaluation
- Nonce-bound, single-use high-risk approvals
- Replay protection
- Local halt switch
- Hash-chained audit events

EVA Core performs no external network calls in v0.1.0.

## Status

v0.1.0 source release. Hosted control plane, fleet halt orchestration, managed retention, and enterprise evidence exports are not included.
